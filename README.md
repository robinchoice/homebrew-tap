# Homebrew tap for Savor

[Savor](https://github.com/robinchoice/savor) is a workspace for the coding agents you already use: Claude Code, Codex, OpenCode, Grok Build or Antigravity. Every task reports back with an acknowledgement, questions you answer in one click and a result.

```sh
brew install --cask robinchoice/tap/savor
```

The app updates itself. The cask follows each release within about two hours.
